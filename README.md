# Billing-WangonNet

Struktur awal halaman utama eBilling sudah disiapkan dalam file `index.html`.

Catatan: halaman ini masih berupa prototipe statis untuk struktur antarmuka utama. Modul yang ditampilkan belum memiliki backend, autentikasi, atau proses bisnis yang aktif. Menu seperti `Login API Service`, `Users`, dan `Informasi Logout` saat ini masih sebatas penanda struktur informasi.

## Isi awal

- Sidebar modul utama eBilling
- Ringkasan dashboard utama
- Blok manajemen data
- Blok operasional
- Blok keuangan dan laporan
- Blok API dan sistem

## Cara membuka

Cukup buka file `index.html` langsung di browser untuk melihat prototipe dengan navigasi anchor internal dan layout responsif dasar. Aktifkan JavaScript di browser agar penanda item aktif pada sidebar dapat diperbarui saat hash URL berubah.
